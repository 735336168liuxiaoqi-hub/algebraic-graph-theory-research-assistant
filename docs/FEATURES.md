# 功能说明与适用边界

从科研任务是否能完成来理解功能，不按旧 Sage 函数是否同名判断。桌面、API 对话和 MCP 共用同一工具契约；任意第三方 Python 函数并不自动成为模型工具。

## 在哪里使用

| 入口 | 用法 |
| --- | --- |
| 桌面“本地工具” | 按分类选函数，使用中文参数、悬停说明、示例或 JSON 输入 |
| 桌面“图输入”和图旁操作面板 | 准备图、看结构、调布局、保存坐标、导出图片和 TikZ |
| API 科研对话 | 插入图、用自然语言提问、检查计划和实际计算记录 |
| MCP | 主 agent 按需读取契约，提交固定步骤、扫描或批量任务 |
| Python 库 | 使用 [Python 接口](reference/PYTHON_API.md)及 API 索引；未开放为工具的接口需由开发者调用 |

## 计算与图形能力

“已覆盖”均指当前文档和工具契约列明的范围。这里评估整体用途，不要求旧接口或旧对象类型相同。

| 科研用途 | 当前情况 | 现有实现或衔接方式 | 仍需处理的部分 |
| --- | --- | --- | --- |
| 统一图输入与复用 | 已覆盖桌面工作流 | 快捷边表/矩阵/graph6/JSON、常见图族、实时预览、鼠标构图、图对象库、配方复用和结果继续使用 | 保留标签、孤立点、方向与权重；拒绝有损适配；数据与编号随执行回执保存，范围见GRAPH_INPUT.md |
| 普通图构造与常见结构变换 | 已覆盖基础范围 | 构图、补图、线图、核心、重编号、剖分、边替换、粘合、图积等 | graph_recipe已有结构选根、组合配方及结构断言；按任务补配方，不按旧名称逐个造接口 |
| 普通图矩阵、谱与多项式 | 已覆盖所列矩阵 | 普通/精确谱工具、A/L/Q/距离等矩阵、特征和匹配多项式 | 大规模精确计算继续受限；不把不同矩阵定义混用 |
| 图能量与能量差 | 数值用途及有限参数认证已覆盖 | 现有能量工具；graph_energy_study对recipe有限整数域作有理根区间比较及精确计根复核 | 单图≤10顶点、参数≤16个；不声称无限参数域定理，未分离为未判定 |
| 加权/复权图计算 | 已覆盖一体化入口 | weighted_graph_spectrum接通显式赋权、厄米复权/有向矩阵、全谱、残差及小规模精确多项式 | D约定显式选择；普通无权谱不改变；非厄米模之和不混称普通能量 |
| 图同构、轨道与商矩阵 | 已覆盖限定规模 | 图比较、轨道划分、等价划分检查、商矩阵 | 搜索与枚举预算保持显式限制 |
| 有限群及对称计数 | 已覆盖基础范围 | 标准循环指标、Cayley图与有向谱工具联动 | 更大群或更多群类型按任务另定；旧getCycleIndex1的非标准编码不作为计数入口 |
| 超图构造与结构变换 | 已覆盖通用组件 | 松路/超星/松圈、六类悬挂研究族、附路、共享根集附边、内部路拼接、克隆、剖分等 | graph_recipe用参数算式及结构断言组合；仍受现有结构操作前提限制，不复用U1/U2旧编号 |
| 超图结构、Perron谱与轨道约化 | 已覆盖文档范围 | 关联、距离、同构、轨道、α谱、赋权关联矩阵、轨道商算子 | 原始点/边轨道代表图不必保留同一对象，但约化后必须验证原图方程和残差 |
| 一致超图张量方程和特征多项式 | 已覆盖，规模受限 | A/L/Q/α张量、特征方程、一般精确消元 | 不声称无限规模可算；遵守一致性与精确/数值输入约定 |
| 指定内部路的识别与关联子矩阵分析 | 已覆盖有界工作流 | hypergraph_path_analysis核验定向松路、歧义及侧分支，提取原图关联/赋权子矩阵 | 非松路拒绝；有歧义需显式边序；赋权仍要求连通一致正权 |
| 精确线性代数与整数方程 | 已覆盖基础范围 | 矩阵代数、行列变换、行列式拆行、整数解族与成立条件 | 已另增分块入口；不要求Sage分块对象 |
| 分块与多项式伴随块研究 | 已覆盖明确定义的构造 | block_matrix_analysis提取、块排列、分块乘积贡献和多项式伴随块对角构造 | ≤16×16；不是Jordan分解；多项式次数及首项系数有限制 |
| 递推、符号求和与级数 | 已覆盖受控通用入口 | linear_recurrence及symbolic_analysis复用SymPy，返回条件、未求值/发散状态与O项 | 白名单算式及资源限制；不承诺一般闭式或全局收敛 |
| 简单图/超图结构绘图、布局与论文代码 | 已覆盖基本工作流及普通图布局入口 | 结构图、拖动顶点、实时曲线、保存坐标、PNG/SVG/PDF和TikZ；graph_layout接通拉普拉斯谱/树/固定点弹簧及坐标变换 | 普通图自动布局至多128点/128边；谱坐标可能不唯一或重合，明确保留原值并说明预览状态；不迁移旧Graphics对象 |
| 科研批量图表与对照输出 | 已覆盖小规模批量实验 | graph_batch_study支持普通图、超图、配方及带权输入，导出对照JSON/CSV/Markdown和可选图集 | ≤12项、累计≤512顶点；带权/有向结构图保留箭头和原权重；失败项目明确保留 |
| 组合路径与棋盘绘图 | 桌面与模型入口已覆盖 | combinatorial_plot接通Matplotlib格路径、按步序号构造、矩形与矩阵棋盘；combinatorial_calculation接通棋盘车多项式 | 路径至多2048步；绘图棋盘每维至多32，车多项式棋盘每维至多10；均使用显式数据，不接收任意回调 |
| 广义线图判定及可验证证书 | 已覆盖有界精确搜索 | graph_class_certificate返回可重构邻接的正证书或可重放的穷尽搜索负证书 | ≤10顶点；状态预算耗尽为未判定；不是短禁图证书 |
| 二维/三维隐式方程绘图 | 仅环境检测 | research_environment检测Matplotlib、scikit-image及SciPy，记录采样/网格/资源需求 | 未实现完整隐式绘图流程，不安装额外环境 |
| 完整TeX文档自动编译成图片/PDF | 仅环境检测 | 检测PATH中的TeX程序；已有TikZ/LaTeX源码与结构图文件输出继续可用 | 发现编译器不等于已验证编译；不自动启动或安装；Windows安装器继续搁置 |

## 工作流能力

开发版新增[反例搜索与独立核验](COUNTEREXAMPLE_SEARCH.md)：固定n/m连通简单图的邻接谱半径反例搜索，2..128顶点、至多1024边。规则策略无需API，模型策略需显式启用；独立精确核验通过才报告反例，未找到不证明猜想成立。

多步骤任务以显式结果字段绑定传值；[批量任务](BATCH.md)支持多案例、依赖预检、独立分支失败处理及汇总。结果页展示概览、表格、图形与实际附件，[成果中心](RESULTS_AND_MEMORY.md)提供课题归类、快照、清理与恢复。

用户记忆保留明确偏好和工具频次；科研经验须审阅后才用于历史参考，不更新模型权重。功能缺口走[独立扩展](EXTENSIONS.md)：先澄清和估算，用户确认后开发、受保护验收，不修改基础工具包。

精确输入、归一化、返回字段与更细限制以[完整工具契约](model/TOOL_REFERENCE.md)为准；可直接填写的例子见[输入手册](OFFLINE_INPUTS.md)。[数值专题](NUMERICS.md)解释高 α 算法与张量特征多项式。历史接口记录仅供[源码追溯](provenance/README.md)。
