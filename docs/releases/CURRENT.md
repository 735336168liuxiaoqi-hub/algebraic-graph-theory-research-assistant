# 当前版本：0.36.0rc5

代数图论科研助手，MIT。仓库保持私有，访问源码与附件需要获授权账号。

## 中英文桌面

顶部“语言 / Language”提供“简体中文”和“English”，即时切换并保存下次启动的选择。覆盖菜单、内置工具名称、参数与枚举说明、常见提示、图形编辑界面和结果标签；已有参数/JSON草稿、模型配置及运行中的计算保留。

`desktop --language en` / `desktop --language zh`可覆盖本次启动。语言偏好在本机账户的 `.graph_research/desktop-language.json`；语言切换不发送模型请求、不增加计算尝试、不改变数学参数或用户记忆中的回答语言。原始图标签、用户内容、模型回复、代码与科研记录不自动翻译，第三方扩展的自定义内容保持可识别原文。

## 安装与使用

[发布页](https://github.com/735336168liuxiaoqi-hub/algebraic-graph-theory-research-assistant/releases/tag/v0.36.0rc5)提供源码ZIP、Python wheel、验证摘要与SHA256清单。完整桌面及保护执行目前在Windows验证，需要64位Python 3.11+；建议3.13。启动器采用 `algebraic graph theory research assistant.exe`，仍使用项目Python环境，不是包含运行时的完整安装器。

43个内置工具及三种入口继续使用同一计算核心。算法、工具原值和调用预算语义未因界面翻译改变。安装和语言操作见[中文使用指南](../../使用指南.md)及[English user guide](../QUICKSTART.md)，能力范围见[功能说明](../FEATURES.md)。

## 验证与边界

双语专项回归覆盖全部内置名称/参数/枚举的英文呈现、两种语言下原值往返、保存失败、原始图与模型ID、草稿保留、已销毁Qt对象，以及计算期间切换；发布附件的验证JSON记录最终验收结果与核心指纹。真实API不作为本次自动测试的一部分。

源码根目录继续仅保留5份Markdown。必要许可、署名和迁移记录保留；旧计划与本地历史备份不随包分发。旧rc4程序附件保留自身的封存内容，升级双语桌面需要安装rc5并重启。

完整隐式三维绘图、自动TeX编译与完整Windows安装器仍未提供。MCP不承诺比直接Python更快或更省模型token；数值结果及有限样例不能代替数学证明。
