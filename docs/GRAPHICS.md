# 图输入、布局与论文图形

安装和首次操作见[使用指南](../使用指南.md)。本页说明同一张图如何从输入进入计算、预览和导出。

## 输入与复用一张图

桌面顶部“图输入”支持边表、邻接/关联矩阵、graph6、图 JSON、常见图族、图对象库和鼠标构图。先选普通图或超图，确认方向、权重和孤立点，再点击“使用此图”应用到兼容工具。比较任务可选左图或右图。

自定义四点普通图可填 `n=4`、边表 `[[0,1],[1,2]]`，其中顶点 3 为孤立点。非一致超图可填 `[[0,1],[1,2,3]]` 来看结构；计算张量谱前仍需满足一致性。

图输入保留原标签、坐标、方向、权重及结构身份。只接受整数编号的计算工具会展示标签与编号对照；不能保留必要信息的工具拒绝有损应用。鼠标删点/删边时，第一次点击预览影响，第二次点击同一对象才删除；点空白处或 Esc 取消。

## 从计算结果绘图

1. 计算前，顶部“绘图与导出”可使用当前参数或准备的图。
2. 计算后，在图旁点“查看结构图”或“绘图 / 布局 / LaTeX”。数值工具一般展示输入图，构图和变换工具展示结果图；多图结果先选择对象。
3. 拖动顶点，连边曲线实时更新。滚轮缩放，“适应窗口”重新适配视野。
4. “保存坐标”得到包含结构与位置的 JSON；之后可通过图输入导回。
5. “图片设置”后点击“生成图片”，再从“图形与文件”另存附件。画布预览本身不表示图片已保存。

结构预览、静态图片和 TikZ 支持普通图、带权图、有向图及正实权超图。箭头和原始权重保留；样式页可保存颜色、线型、字号、自定义文本与标签偏移。静态图支持 PNG/SVG/PDF，具体以当前面板和实际附件为准。

## 自动布局与坐标调整

普通图提供弹簧、圆形、谱等自动布局，以及缩放、旋转、平移、对齐等坐标操作。固定弹簧布局需给完整初始坐标；固定点、根和选择对象使用面板中的编号。超图使用弹簧、圆形和手动拖动。

坐标变换先等比例缩放、绕原点逆时针旋转，再平移。对齐仅影响选中点。谱布局可能重合或不唯一；重合时保存原坐标并报告未生成预览，不自动扰动，也不将布局当作同构证明。

原生预览至多 128 顶点，普通图 1024 边、超图 128 边；自动布局和导出另有工具限制，见[输入手册](OFFLINE_INPUTS.md)。布局使用无向无权支撑结构时，返回的原图文档仍保留方向与权重。

## 导出 LaTeX / TikZ

在图旁打开“LaTeX设置”，选标签、样式等选项，点击“导出LaTeX”。普通图与超图均可使用，文件名按实际对象和导出类型给出；下载或另存真实生成的 `.tex` 附件。

TeX 导出使用当前图与已保存坐标。自定义文本按接口规则处理，不能借文本执行代码。生成源码不需要安装 TeX；编译成 PDF 需另配 TeX 环境，当前未提供自动完整编译流程。

TeX 中的顶点、曲线控制点、箭头和标签位置默认最多保留四位小数，去掉尾零和负零；若取整会使不同顶点重合或整段非零路径消失，自动增加精度，必要时保留完整精度。完整文档和 TikZ 片段使用同一规则。此处理仅发生在 TeX 导出时，不改变原始坐标、保存的 JSON、计算结果或 PNG/SVG/PDF 图片导出。

图输入/结构预览、原生布局编辑器、论文示意图的画布下方均提供默认关闭的“显示顶点坐标”。开启后可切换“原始坐标 / TeX 导出坐标”及“全部顶点 / 仅选中顶点”，拖动时实时更新；仅选中模式显示正在选择或最近点击的顶点。原始坐标为逻辑坐标，并非屏幕像素；显示值按导出精度规则缩短，保存值仍保留完整精度。普通结构图的 TeX 坐标包含默认居中和最长跨度 10cm 的等比例缩放，论文示意图直接使用其 cm 坐标。坐标提示不写入图片、TeX 标签或布局文件，滚轮缩放视野不会改变坐标。离线 HTML 布局编辑器也提供同样的显示选项。

## 整张图的可见标签

在图输入、结构预览、原生布局编辑器或论文示意图的画布下方，找到“图标签”，输入 `G_1`、`H_k`、`G_{n+1}` 或“图(a)”，选择图上方/下方及字号，再点击“应用标签”。简单下标记法和 Unicode 上下标会显示为相应标记；其他内容按普通文本处理，不执行用户输入的 TeX 命令。

在“拖动顶点 / 拖动锚点”模式下可直接拖动图标签微调位置；清空文字后应用可移除。结构预览和论文示意图可用原有撤销按钮恢复标签修改。视野外的标签可点击“适应窗口”查看。

标签单独保存为 `style.graph_label`，不替换文件名称、顶点标签或边编号，不改变图结构和计算输入。保存布局 JSON 后可恢复文字、相对位置和字号；图输入/结构预览导出的 PNG/SVG/PDF、普通图和超图 TikZ，以及论文示意图的 SVG/TeX 均包含标签。示意图展开成具体超图或从完整图导入示意图时保留整图标签。

程序调用可在完整图对象或示意图的样式中提供：

```json
{"graph_label":{"text":"H_k","position":"below","offset":[0,0],"font_size":12,"color":"#233c47"}}
```

`offset` 为相对最长图跨度的二维偏移，向右/向上为正，范围为 ±5；拖动会自动保存该值。标签不参与原图的归一化，因此新增、移动标签不会改变已有顶点的 TeX 坐标。未添加标签的旧图保持原有输出。

## 不确定长度的论文示意图

顶部“论文示意图”是独立的符号绘图场景，支持中心边、省略超路、边内省略点、参数标签和花括号。可以继续用鼠标加点/加边，保存场景 JSON，导出 SVG 或 TeX；原结构图流程仍保留。

连续中心边的填充与边界分层绘制，避免后画边遮住已有边界。两端点中心边的省略点沿边方向排列，多点中心边默认居中；参数旁的说明给出作用对象与含义。重复点击已选边可取消选择；画布视图可手动调整，编辑时避免反复自动适配引起点击位置跳动。

含省略号的超路表示符号结构，不是一个确定规模的计算图。需要计算时，先明确长度等参数，再展开为具体图并检查结构；不要把示意图坐标或省略号当作数值输入。

## 模型与程序调用

图旁的手动导出直接本地执行，不需额外模型请求。API/MCP 通过 `graph_layout`、`graph_tikz`、`hypergraph_tikz` 等原工具名调用，图形与论文示意图的完整参数见[工具契约](model/TOOL_REFERENCE.md)。可复用 [布局到 TikZ 示例](../examples/library_entries/layout-to-tikz.mcp.json)。

## 双语摘要与颜色控件

图输入、图对象库、预览选择器和论文示意图展开结果使用结构化中英文摘要，区分顶点、普通边、有向边和超边；空超图显示“无超边 / No hyperedges”。“输入图 / Input graph”“结果图 / Result graph”“结构预览 / Structure preview”随界面切换，原始图名、标签和数据不重写，系统生成的“已展开”标记按语言显示。

论文示意图的线宽和颜色位于独立样式行。三个颜色按钮分别为“线条颜色 / Line color”“顶点颜色 / Vertex color”“超边填充 / Hyperedge fill”，自适应标签宽度并显示色样，悬停查看当前色号。选择颜色后画布与色样同步，载入其他场景后同步显示其设置；取消选择不会修改图形。填充色控制中心超边的填充，不是画布背景。
