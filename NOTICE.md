# Source provenance and attribution

Algebraic Graph Theory Research Assistant was developed from mathematical requirements and the retained portions of eleven Sage research files supplied for this project, using native Python implementations and Python libraries.

Some supplied files identify **Haiying Shan** as the copyright holder (2014–2023, varying by file). This attribution remains part of the provenance record for the retained code.

The original file names, SHA-256 digests, definition locations, adaptation notes and Python mappings are preserved in `docs/provenance/migration_catalog.json`, `MIGRATION_STATUS.md` and `SAGE_REMAINING_REVIEW.md`. Historical source excerpts are documentation only; they are excluded from the runtime Python wheel and are not executable model tools.

**Publication permission is confirmed by the project owner (2026-10-20).** The owner has authorized publication of the supplied code and adaptations and selected the MIT License. See LICENSE, LICENSE-STATUS.md and docs/provenance/rights-status.json. Original attribution remains part of the distribution; pending-authorization notes in earlier release records describe historical candidates, not the current release.

Python, NumPy, NetworkX, SymPy, Matplotlib, PySide6/Qt, LangGraph, HTTPX, jsonschema, the MCP SDK and other dependencies retain their respective upstream licenses. They are installed separately; the candidate source archive and wheel do not bundle a Python runtime or a complete dependency environment.
